    Learning objectives

    • Apply Gaussian Mixture Models (GMMs) to perform unsupervised image segmentation.

    • Compare segmentation results across different numbers of clusters.

    • Combine multiple MR image contrasts to improve clustering performance.

    • Map clustered labels back onto image slices and volumes.

    • Visualise and interpret segmentation results using image plots and exploratory feature visualisations.

    This part of the lesson seeks to demonstrate how Gaussian Mixture Models can be applied beyond controlled synthetic examples to more realistic data scenarios. By working with fitted models and visualising their behaviour across a continuous state space, it illustrates how probabilistic predictions and likelihood surfaces can be interpreted, spatially. The focus is on connecting the mathematical outputs of a GMM to intuitive, visual insights about structure, uncertainty, and model behaviour in practice.

    Now we can fit the GMM estimator using the suspected number of two components.

    clf = GaussianMixture(n_components=2)

clf.fit(X_train)

resolution = 100

vec_a = linspace(0.8*min(X_train[:,0]), 1.2*max(X_train[:,0]), resolution)
vec_b = linspace(0.8*min(X_train[:,1]), 1.2*max(X_train[:,1]), resolution)

grid_a, grid_b = meshgrid(vec_a, vec_b)

XY_statespace = c_[grid_a.ravel(), grid_b.ravel()]

Z_score = clf.score_samples(XY_statespace)

Z_s = Z_score.reshape(grid_a.shape)


fig, ax = subplots(figsize=(8, 6))

cax = ax.contour(grid_a, grid_b, -Z_s,
           norm=LogNorm(vmin=1.0, vmax=1000.0),
           levels=logspace(0, 3, 10),
           cmap='magma'
          )

fig.colorbar(cax);

ax.scatter(X_train[:, 0], X_train[:, 1], .8)

title('Negative log-likelihood of Prediction', fontsize=16)
axis('tight');

show()

scoring = adjusted_rand_score(y_gender, y_predict)
